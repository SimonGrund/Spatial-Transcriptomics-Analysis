# Spatial Transcriptomics

**Author:** Disha Kshirsagar

## Overview

This repository contains analysis and data processing scripts for Spatial Transcriptomics.

## Structure

- `RCTD.R`: R script for Robust Cell Type Decomposition (RCTD).
- `Data/`: Contains processed and raw data.
  - `RCTD_processed.rds`: Processed RCTD object.
  - `scRNA/`: Single-cell RNA sequencing data.
  - `spatial/`: Spatial transcriptomics data.
- `Results/`: Output results.
